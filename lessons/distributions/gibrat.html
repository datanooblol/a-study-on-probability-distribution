Gibrat

scipy.stats.gibrat

Intuition

Gibrat's distribution is simply a lognormal with the underlying normal fixed at mean 0 and standard deviation 1 -- it embodies 'Gibrat's law,' the classic finding that firm and city sizes grow by random multiplicative percentage shocks rather than fixed additive amounts.

Formula

\[ f(x) = \frac{1}{x\sqrt{2\pi}}e^{-(\ln x)^2/2}, \quad x > 0 \]
parameterdefault used heremeaning

Use cases

  • Gibrat's law: modeling proportional growth of firm and city sizes
  • Multiplicative random-growth processes in economics

A funny example

A kid's lemonade stand doubles or shrinks by a random percentage each month rather than gaining or losing a fixed number of dollars -- run that multiplicative randomness for a while and the stand's eventual size follows Gibrat's distribution.

What's the probability the lemonade stand's relative size ends up above 2 (i.e. more than double the baseline)?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.gibrat()
print('P(size > 2x):', round(dist.sf(2), 4))
print('median size:', round(dist.median(), 4))
P(size > 2x): 0.2441 median size: 1.0
