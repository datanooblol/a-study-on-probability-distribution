Folded Cauchy

scipy.stats.foldcauchy

Intuition

Take a Cauchy distribution (famous for wild, mean-less outliers) and fold the negative half onto the positive side by taking absolute values -- you get a distribution of magnitudes that still has the Cauchy's notoriously heavy, unpredictable tail.

Formula

\[ f(x;c) = \frac{1}{\pi(1+(x-c)^2)} + \frac{1}{\pi(1+(x+c)^2)}, \quad x \ge 0 \]
parameterdefault used heremeaning
c1location of the original (pre-folding) Cauchy peak

Use cases

  • Modeling absolute measurement error magnitude with heavy tails
  • Robustness testing for statistical estimators against extreme outliers

A funny example

A weather vane's compass error is Cauchy-distributed around a slightly off-center reading, and a kid only cares about the size of the error, not its direction, so all the negative errors get folded on top of the positive ones.

What's the probability the folded error exceeds 3 units?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.foldcauchy(c=1)
print('P(|error| > 3):', round(dist.sf(3), 4))
print('median error magnitude:', round(dist.median(), 4))
P(|error| > 3): 0.2256 median error magnitude: 1.4142
