Zipfian

scipy.stats.zipfian

Intuition

Zipfian is the finite-vocabulary version of the Zipf distribution -- instead of an infinite list of ranks, there are only n possible ranks (like the n most common words in a specific book), which matters when a=1 doesn't even work for infinite Zipf but works perfectly well here.

Formula

\[ f(k;a,n) = \frac{1/k^a}{H_{n,a}}, \quad k=1,2,\ldots,n \]
parameterdefault used heremeaning
a1.2shape parameter (tail exponent), a >= 0
n10number of distinct ranks (finite vocabulary size)

Use cases

  • Word frequency modeling for finite vocabularies (limited corpora)
  • Recommendation system and catalog popularity modeling with a fixed item count

A funny example

A kid's picture book only has 10 distinct words total. Some words (like 'the' and 'cat') repeat constantly while others barely show up, following the same rank-based power-law pattern as Zipf's law but capped at exactly 10 possible words.

What's the probability a randomly picked word instance is one of the top-3 most common words?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.zipfian(a=1.2, n=10)
print('P(rank <= 3):', round(dist.cdf(3), 4))
print('mean rank:', round(dist.mean(), 4))
P(rank <= 3): 0.6901 mean rank: 3.0261
