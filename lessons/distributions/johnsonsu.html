Johnson SU (unbounded)

scipy.stats.johnsonsu

Intuition

Johnson SU transforms a normal variable through an inverse-hyperbolic-sine function to produce a flexible, unbounded distribution that can be skewed and either lighter- or heavier-tailed than normal -- widely used in finance because it fits real skewed asset-return data much better than a plain normal curve.

Formula

\[ f(x;a,b) = \frac{b}{\sqrt{x^2+1}\sqrt{2\pi}}\exp\!\left(-\frac{1}{2}\left(a+b\,\text{arcsinh}(x)\right)^2\right) \]
parameterdefault used heremeaning
a1shape parameter controlling skewness
b2shape parameter controlling tail behavior

Use cases

  • Financial return and risk modeling (skewed, fat-tailed data)
  • Fitting arbitrary skewed continuous data via the Johnson distribution system

A funny example

A kid's daily allowance changes each week by an amount that's usually small but can occasionally swing much further in one direction than the other -- unlike a normal bell curve, this shape lets the swings be properly lopsided and fat-tailed.

What's the probability this week's change is less than -1?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.johnsonsu(a=1, b=2)
print('P(X < -1):', round(dist.cdf(-1), 4))
print('mean:', round(dist.mean(), 4))
P(X < -1): 0.2228 mean: -0.5905
