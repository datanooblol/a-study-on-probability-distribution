Noncentral t

scipy.stats.nct

Intuition

This is the distribution of a t-statistic when the true effect being tested isn't actually zero -- it's the key ingredient for computing the statistical power of a t-test (the chance of correctly detecting a real effect of a given size before you even collect data).

Formula

\[ f(x;\nu,\delta) = \frac{\nu^{\nu/2}\exp\!\left(-\frac{\nu\delta^2}{2(x^2+\nu)}\right)}{\sqrt{\pi}\,\Gamma(\nu/2)\,2^{(\nu-1)/2}(\nu+x^2)^{(\nu+1)/2}}\int_0^\infty y^\nu \exp\!\left[-\frac{1}{2}\left(y-\frac{\delta x}{\sqrt{\nu+x^2}}\right)^2\right]dy \]
parameterdefault used heremeaning
df10degrees of freedom
nc2noncentrality parameter (standardized effect size)

Use cases

  • Statistical power analysis for t-tests in experimental design
  • Confidence interval construction for standardized effect sizes

A funny example

A kid wants to know if a new fertilizer really makes plants grow taller. If the fertilizer genuinely works by some real amount, the t-statistic from comparing treated vs. untreated plants follows this noncentral-t shape instead of the ordinary symmetric t distribution.

What's the probability the t-statistic exceeds 2.0, given the fertilizer has this real effect size?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.nct(df=10, nc=2)
print('P(t > 2.0):', round(dist.sf(2.0), 4))
print('mean t:', round(dist.mean(), 4))
P(t > 2.0): 0.519 mean t: 2.1674
