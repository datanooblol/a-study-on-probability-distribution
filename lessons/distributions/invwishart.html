Inverse Wishart

scipy.stats.invwishart

Intuition

The matrix version of 'flip it upside down': if a covariance matrix is Wishart-distributed, its inverse is Inverse-Wishart. It's the standard Bayesian prior for an unknown covariance matrix, the same role Inverse-Gamma plays for a single unknown variance.

Formula

\[ f(\mathbf{X}) \propto |\mathbf{X}|^{-\frac{df+p+1}{2}} e^{-\frac{1}{2}\text{tr}(\Sigma \mathbf{X}^{-1})} \]
parameterdefault used heremeaning
df5degrees of freedom
scale[[1, 0], [0, 1]]the underlying scale matrix

Use cases

  • Bayesian prior for an unknown covariance matrix
  • Hierarchical models in Bayesian statistics (e.g. Gaussian mixture priors)

A funny example

A scientist doesn't know in advance how two ingredients in a recipe wobble together, so before seeing any data they draw a plausible 'recipe wobble matrix' from a big bag of reasonable guesses.

What does one such randomly-guessed wobble matrix look like, before any real data is seen?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.invwishart(df=5, scale=np.eye(2))
sample = dist.rvs(random_state=0)
print('one sampled covariance matrix:')
print(np.round(sample, 3))
one sampled covariance matrix: [[ 0.223 -0.558] [-0.558 3.401]]
Theoretical shape at the default parameters above (blue = density/PMF, orange = CDF).
