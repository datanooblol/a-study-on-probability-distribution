Folded Normal

scipy.stats.foldnorm

Intuition

If a measurement error is normally distributed around some nonzero true value but you can only observe its magnitude (like a distance, which can't be negative), the result is a folded normal -- a normal curve with its negative half flipped up on top of the positive half.

Formula

\[ f(x;c) = \sqrt{\frac{2}{\pi}}\cosh(cx)\exp\!\left(-\frac{x^2+c^2}{2}\right), \quad x \ge 0 \]
parameterdefault used heremeaning
c1.5location of the original (pre-folding) normal mean, in std-dev units

Use cases

  • Modeling absolute measurement error when only magnitude is observable
  • Manufacturing tolerance analysis for dimensions that can't be negative

A funny example

A kid's toy car is supposed to stop exactly 1.5 meters from a wall, but bumps and wobbles push it a normal-random amount off target in either direction. Since the kid only measures how far the car ended up from the target (never which direction), the negative misses get folded into positive distances.

What's the probability the car's measured distance from target exceeds 1 meter?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.foldnorm(c=1.5)
print('P(distance > 1):', round(dist.sf(1), 4))
print('mean distance:', round(dist.mean(), 4))
P(distance > 1): 0.6977 mean distance: 1.5586
