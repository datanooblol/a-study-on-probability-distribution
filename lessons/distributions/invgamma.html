Inverse Gamma

scipy.stats.invgamma

Intuition

The inverse gamma is exactly what you get by taking 1/X when X follows a gamma distribution -- it's the standard conjugate Bayesian prior for an unknown variance, because it keeps the math tidy when combined with normal-distributed data.

Formula

\[ f(x;a) = \frac{x^{-a-1}e^{-1/x}}{\Gamma(a)}, \quad x > 0 \]
parameterdefault used heremeaning
a4shape parameter

Use cases

  • Conjugate Bayesian prior for variance parameters
  • Modeling reciprocal quantities like precision-to-variance conversions

A funny example

A scientist isn't sure how 'wobbly' a new measuring instrument is, so they use the inverse gamma distribution as their starting guess for the wobble size (the variance) before collecting any real data to update their belief.

What's the probability the guessed variance is less than 0.5, and what's the expected variance guess?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.invgamma(a=4)
print('P(variance < 0.5):', round(dist.cdf(0.5), 4))
print('expected variance:', round(dist.mean(), 4))
P(variance < 0.5): 0.8571 expected variance: 0.3333
