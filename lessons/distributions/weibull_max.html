Weibull Maximum

scipy.stats.weibull_max

Intuition

The mirror image of the ordinary (minimum) Weibull distribution, reflected onto the negative numbers -- it's the exact distribution of the maximum of many Weibull-tailed values, used whenever the quantity of interest is naturally capped from above rather than below.

Formula

\[ f(x;c) = c\,(-x)^{c-1}\exp\!\left(-(-x)^c\right), \quad x \le 0 \]
parameterdefault used heremeaning
c1.5shape parameter

Use cases

  • Modeling maximum values with a hard upper physical limit
  • Extreme value theory: minimal-strength-link reflected onto maxima

A funny example

A kid tracks the highest score anyone gets across many rounds of a game where scores are Weibull-shaped and can never exceed a hard ceiling of 0 (measured as 'distance below the maximum possible score'), so it always comes out negative or zero.

What's the probability the score is above -1 (close to the ceiling)?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.weibull_max(c=1.5)
print('P(X > -1):', round(dist.sf(-1), 4))
print('mean:', round(dist.mean(), 4))
P(X > -1): 0.6321 mean: -0.9027
