Hyperbolic Secant

scipy.stats.hypsecant

Intuition

A symmetric, bell-shaped curve that sits between the normal and Cauchy distributions in tail weight -- lighter tails than Cauchy but heavier than normal -- and turns up naturally in the physics of optical soliton pulses.

Formula

\[ f(x) = \frac{1}{\pi}\,\text{sech}(x) \]
parameterdefault used heremeaning

Use cases

  • Optical soliton pulse shape modeling in physics
  • Symmetric moderate-tailed alternative to the normal distribution

A funny example

A kid strums a guitar string and watches the vibration pulse spread out; the shape of that pulse's envelope traces out this exact hyperbolic-secant bump, a little fatter in the tails than a plain bell curve.

What's the probability the pulse's measured value falls between -1 and 1?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.hypsecant()
print('P(-1 < X < 1):', round(dist.cdf(1) - dist.cdf(-1), 4))
print('variance:', round(dist.var(), 4))
P(-1 < X < 1): 0.5512 variance: 2.4674
