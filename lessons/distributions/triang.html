Triangular

scipy.stats.triang

Intuition

The simplest possible 'best guess plus a range' distribution: given only a minimum, maximum, and single most-likely value, the triangular distribution is the natural shape to draw between them, which is why it's a staple of project-planning and simulation software.

Formula

\[ f(x;c) = \begin{cases} \dfrac{2x}{c}, & 0 \le x \le c \\[4pt] \dfrac{2(1-x)}{1-c}, & c \le x \le 1 \end{cases} \]
parameterdefault used heremeaning
c0.5location of the peak, as a fraction of the support

Use cases

  • Project management time/cost estimation (PERT-style triangular estimates)
  • Monte Carlo simulation input when only min/max/mode are known

A funny example

A kid estimates how long it'll take to finish a jigsaw puzzle: it definitely won't be done in 5 minutes, definitely won't take 3 hours, and their best single guess is right around 45 minutes -- so the probability ramps up to that guess and back down.

What's the probability the puzzle takes less time than the peak guess (X < 0.5)?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.triang(c=0.5)
print('P(X < 0.5):', round(dist.cdf(0.5), 4))
print('mean:', round(dist.mean(), 4))
P(X < 0.5): 0.5 mean: 0.5
