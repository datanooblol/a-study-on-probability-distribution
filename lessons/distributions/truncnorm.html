Truncated Normal

scipy.stats.truncnorm

Intuition

A normal distribution with the tails chopped off and the remaining middle rescaled to still integrate to 1 -- essential whenever you know a normally-behaved quantity has hard physical limits, like a test score that can't go below 0 or above 100.

Formula

\[ f(x;a,b) = \frac{\phi(x)}{\Phi(b)-\Phi(a)}, \quad a \le x \le b \]
parameterdefault used heremeaning
a-2lower truncation bound (in standard-deviation units)
b2upper truncation bound (in standard-deviation units)

Use cases

  • Modeling physically bounded normal quantities (test scores, physical dimensions)
  • Bayesian priors with hard constraints on parameter ranges

A funny example

A carnival ring-toss game scores points that would naturally spread out like a bell curve, but the machine only displays scores between -2 and 2 standard deviations from average, clipping off anything wilder than that.

What's the probability a displayed score falls between -1 and 1?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.truncnorm(a=-2, b=2)
print('P(-1 < X < 1):', round(dist.cdf(1) - dist.cdf(-1), 4))
print('mean:', round(dist.mean(), 4))
P(-1 < X < 1): 0.7152 mean: 0.0
