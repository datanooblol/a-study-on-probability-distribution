Yule-Simon

scipy.stats.yulesimon

Intuition

Yule-Simon arises from a 'rich get richer' preferential-attachment process -- new items are more likely to join whichever category is already popular -- producing a power-law tail that famously matches the sizes of biological genera, city populations, and the popularity of web links.

Formula

\[ f(k;\alpha) = \alpha\,B(k,\alpha+1), \quad k=1,2,3,\ldots \]
parameterdefault used heremeaning
alpha2.5shape parameter controlling the power-law tail decay

Use cases

  • Preferential attachment / 'rich get richer' network and popularity modeling
  • Word frequency and city population size-rank modeling (power-law tails)

A funny example

In a school where new kids always want to join whichever club is already the most popular, club sizes end up following the Yule-Simon distribution: most clubs stay tiny, but a few snowball into being enormous because popularity attracts even more popularity.

What's the probability a randomly chosen club has exactly 3 members?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.yulesimon(alpha=2.5)
print('P(exactly 3 members):', round(dist.pmf(3), 4))
print('mean club size:', round(dist.mean(), 4))
P(exactly 3 members): 0.0577 mean club size: 1.6667
