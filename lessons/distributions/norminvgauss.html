Normal Inverse Gaussian

scipy.stats.norminvgauss

Intuition

Built by mixing a normal distribution with random variance drawn from an inverse Gaussian, this produces a bell-shaped curve with fatter tails and adjustable skew -- a mainstay of quantitative finance for modeling stock returns, which are never quite as tame as a plain normal curve suggests.

Formula

\[ f(x;a,b) = \frac{a\,K_1\!\left(a\sqrt{1+x^2}\right)}{\pi\sqrt{1+x^2}}\exp\!\left(\sqrt{a^2-b^2}+bx\right) \]
parameterdefault used heremeaning
a2tail-heaviness parameter, alpha (a > 0)
b0.5skewness (asymmetry) parameter, beta (|b| < a)

Use cases

  • Financial asset return modeling with fat tails and skew
  • Turbulence and physical fluctuation modeling

A funny example

A kid tracks their video game high scores each week. The scores cluster around a typical level like a bell curve, but every so often there's a much bigger jump (or drop) than a plain bell curve would predict -- exactly the extra 'fat tail' this distribution is built to capture.

What's the probability this week's score change exceeds 1.5?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.norminvgauss(a=2, b=0.5)
print('P(X > 1.5):', round(dist.sf(1.5), 4))
print('mean:', round(dist.mean(), 4))
P(X > 1.5): 0.0536 mean: 0.2582
