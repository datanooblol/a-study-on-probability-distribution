Wrapped Cauchy

scipy.stats.wrapcauchy

Intuition

Take the notoriously heavy-tailed Cauchy distribution and wrap it around a circle like winding string around a spool -- the result keeps a distinctive sharply-peaked, heavy-tailed circular shape, useful for directional data with occasional wild outlier angles.

Formula

\[ f(x;c) = \frac{1-c^2}{2\pi(1+c^2-2c\cos x)}, \quad 0 \le x \le 2\pi \]
parameterdefault used heremeaning
c0.5shape parameter, 0 < c < 1 (higher = tighter clustering)

Use cases

  • Circular statistics with heavy-tailed, outlier-prone directional data
  • Modeling wind direction data with occasional extreme gusts

A funny example

A spinning arrow on a board mostly points in one favorite direction but every so often flings around wildly to point almost anywhere, more dramatically than the gentler von Mises weathervane would predict.

What's the probability the arrow's angle falls within 1 radian of its favorite direction?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

import numpy as np
dist = stats.wrapcauchy(c=0.5)
p_near_zero = dist.cdf(1) + dist.sf(2*np.pi - 1)
print('P(within 1 rad of favorite dir):', round(p_near_zero, 4))
print('variance:', round(dist.var(), 4))
P(within 1 rad of favorite dir): 0.6512 variance: 5.6188
