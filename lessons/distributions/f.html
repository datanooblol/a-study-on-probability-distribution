F

scipy.stats.f

Intuition

The distribution of a *ratio* of two independent Chi-square variables (each divided by its own degrees of freedom). Because it compares two spread-out-of-squares numbers, it's the natural tool for asking 'is group A more variable than group B?' or 'does adding these extra variables actually explain more variance?'

Formula

\[ f(x) = \frac{\sqrt{\frac{(d_1 x)^{d_1} d_2^{d_2}}{(d_1 x + d_2)^{d_1+d_2}}}}{x\,B(d_1/2,\,d_2/2)}, \quad x \ge 0 \]
parameterdefault used heremeaning
dfn5numerator degrees of freedom
dfd10denominator degrees of freedom

Use cases

  • ANOVA: comparing variance between multiple groups
  • Comparing the variances of two samples
  • The F-test in regression (does a set of predictors explain significant variance?)

A funny example

Two classes take the same quiz. Class A's scores are more spread out than Class B's. A teacher wants a number that captures 'how much more spread out'.

If the two classes were really equally variable, what's the chance the observed spread ratio would be this large just by chance?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.f(dfn=5, dfd=10)
print('P(ratio >= 3):', round(dist.sf(3), 4))
print('critical value (95%):', round(dist.ppf(0.95), 4))
P(ratio >= 3): 0.0656 critical value (95%): 3.3258
