Random Correlation Matrix

scipy.stats.random_correlation

Intuition

Generates a random, valid correlation matrix (1's on the diagonal, everything between -1 and 1 off it) that matches a chosen set of eigenvalues -- useful for stress-testing portfolios or simulations against a specific 'how correlated is everything' profile.

Formula

\[ \text{Correlation matrices } \mathbf{R} \text{ with prescribed eigenvalues } \{\lambda_i\}, \textstyle\sum \lambda_i = n \]
parameterdefault used heremeaning
eigs[0.5, 0.8, 1.2, 1.5]desired eigenvalues (must sum to the dimension)

Use cases

  • Stress-testing portfolio risk models against specific correlation structures
  • Simulating multivariate data with a controlled correlation profile

A funny example

A teacher wants to randomly pair up how strongly every subject's grades relate to every other subject's grades (math with science, science with art, etc.), while keeping the overall 'total relatedness' fixed at a chosen amount.

What does one such random, valid correlation matrix between 4 subjects look like?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

sample = stats.random_correlation.rvs(eigs=[0.5, 0.8, 1.2, 1.5], random_state=0)
print('one random correlation matrix:')
print(np.round(sample, 3))
one random correlation matrix: [[ 1. -0.132 0.014 -0.24 ] [-0.132 1. 0.457 0.017] [ 0.014 0.457 1. 0.076] [-0.24 0.017 0.076 1. ]]
