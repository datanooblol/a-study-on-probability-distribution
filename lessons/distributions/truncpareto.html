Truncated Pareto

scipy.stats.truncpareto

Intuition

Pure Pareto distributions have an infinite upper tail, but real-world 'power law' quantities (city populations, crater sizes, word frequencies) always run into a practical ceiling -- truncated Pareto keeps the classic power-law shape while enforcing that hard upper limit.

Formula

\[ f(x;b,c) = \frac{b}{1-c^{-b}}\,\frac{1}{x^{b+1}}, \quad 1 \le x \le c \]
parameterdefault used heremeaning
b2Pareto shape (tail index)
c10upper truncation point (standardized so support is [1, c])

Use cases

  • Modeling power-law data with a known physical or empirical upper limit
  • City size, crater size, and word-frequency distributions with finite bounds

A funny example

A kid catalogs the sizes of craters on the moon in a textbook. Crater sizes follow a power-law pattern where small craters vastly outnumber large ones, but the biggest crater in the book can't be bigger than the single largest one ever recorded.

What's the probability a randomly chosen crater size (in these units) exceeds 5?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.truncpareto(b=2, c=10)
print('P(size > 5):', round(dist.sf(5), 4))
print('mean size:', round(dist.mean(), 4))
P(size > 5): 0.0303 mean size: 1.8182
