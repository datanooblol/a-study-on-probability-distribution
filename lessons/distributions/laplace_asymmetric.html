Asymmetric Laplace

scipy.stats.laplace_asymmetric

Intuition

This stretches the classic 'double exponential' Laplace distribution so one side decays faster than the other, giving a sharp peak with two differently-weighted tails -- it's the backbone of quantile regression, since minimizing an asymmetric loss naturally produces this distribution.

Formula

\[ f(x;\kappa) = \begin{cases} \dfrac{1}{\kappa+\kappa^{-1}}e^{-x\kappa}, & x \ge 0 \\[4pt] \dfrac{1}{\kappa+\kappa^{-1}}e^{x/\kappa}, & x < 0 \end{cases} \]
parameterdefault used heremeaning
kappa2asymmetry parameter (1 gives the ordinary symmetric Laplace)

Use cases

  • Quantile regression and asymmetric loss modeling in statistics
  • Financial modeling of asymmetric gains/losses

A funny example

A kid's daily walk to school usually takes about the same time, but when they're late they tend to be only a little late, while on lucky fast days they can sometimes shave off a lot more time than usual -- the two sides of their timing error aren't equally spread.

What's the probability the time deviation is more negative than -1 (running notably early)?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.laplace_asymmetric(kappa=2)
print('P(X < -1):', round(dist.cdf(-1), 4))
print('mean:', round(dist.mean(), 4))
P(X < -1): 0.4852 mean: -1.5
