Kappa 4

scipy.stats.kappa4

Intuition

Kappa 4 is a 'master' distribution: by dialing its two shape parameters h and k, it reproduces the logistic, Gumbel, exponential, uniform, generalized extreme value, and generalized Pareto distributions all as special cases, making it a favorite for flood-frequency analysis where analysts want one flexible family to try many shapes.

Formula

\[ f(x;h,k) = (1-kx)^{1/k-1}\left(1-h(1-kx)^{1/k}\right)^{1/h-1} \]
parameterdefault used heremeaning
h0.5shape parameter controlling tail type
k0.2shape parameter controlling skewness/support bound

Use cases

  • Flood-frequency and hydrological extreme value analysis
  • Unifying framework for fitting several extreme-value distribution families

A funny example

A river's yearly flood height can be modeled with two dials, h and k. Depending on how those dials are set, this one distribution can mimic several completely different flood-risk shapes that scientists have used in the past.

What's the probability the flood height exceeds 1 unit at these dial settings?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.kappa4(h=0.5, k=0.2)
print('P(flood height > 1):', round(dist.sf(1), 4))
print('mean flood height:', round(dist.mean(), 4))
P(flood height > 1): 0.3008 mean flood height: 0.6489
