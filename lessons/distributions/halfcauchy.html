Half-Cauchy

scipy.stats.halfcauchy

Intuition

Take a Cauchy distribution and fold it at zero: you get a distribution that's zero most likely value but with a notoriously heavy tail, which makes it a favorite 'weakly informative' prior for scale parameters in Bayesian statistics because it barely constrains large values.

Formula

\[ f(x) = \frac{2}{\pi(1+x^2)}, \quad x \ge 0 \]
parameterdefault used heremeaning

Use cases

  • Weakly-informative Bayesian prior for scale/variance parameters
  • Modeling absolute values of heavy-tailed measurement errors

A funny example

A kid guesses how tall a mystery tower might be, having almost no idea -- their guess is usually small, but they leave the door wide open for it to occasionally be enormous, much more so than a normal-based guess would allow.

What's the probability the guessed height exceeds 5 units?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.halfcauchy()
print('P(X > 5):', round(dist.sf(5), 4))
print('median:', round(dist.median(), 4))
P(X > 5): 0.1257 median: 1.0
