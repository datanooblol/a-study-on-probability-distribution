Von Mises (linear support)

scipy.stats.vonmises_line

Intuition

This uses the exact same formula as the circular von Mises distribution, but scipy treats it as an ordinary distribution on the real line (no wraparound at the edges) -- useful when you want the von Mises bump shape for a bounded linear quantity rather than a genuinely circular one.

Formula

\[ f(x;\kappa) = \frac{e^{\kappa\cos x}}{2\pi I_0(\kappa)}, \quad -\pi \le x \le \pi \]
parameterdefault used heremeaning
kappa3concentration parameter (higher = tighter clustering around the mean)

Use cases

  • Bounded-interval bump-shaped data without circular wraparound semantics
  • Modeling concentrated data on a fixed linear range using the von Mises shape

A funny example

A kid uses the same 'clustered bump' shape as the weathervane example, but this time to describe a swing's push-strength setting on a fixed dial from -pi to pi, where the two ends of the dial are treated as genuinely different, not wrapped together.

What's the probability the dial setting falls within 1 unit of its most likely value?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.vonmises_line(kappa=3)
print('P(-1 < X < 1):', round(dist.cdf(1) - dist.cdf(-1), 4))
print('mean:', round(dist.mean(), 4))
P(-1 < X < 1): 0.8809 mean: -0.0
