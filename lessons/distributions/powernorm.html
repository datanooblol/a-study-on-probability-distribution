Power Normal

scipy.stats.powernorm

Intuition

Like power lognormal but built from a normal core instead: raising the normal survival function to a power c gives the lifetime distribution of a series system of c normally-distributed components, skewing the familiar bell curve toward earlier failure.

Formula

\[ f(x;c) = c\,\phi(x)\left[\Phi(-x)\right]^{c-1} \]
parameterdefault used heremeaning
c2power exponent applied to the normal CDF

Use cases

  • Series-system reliability modeling with normally-distributed component lifetimes
  • Order statistics of normal samples (extreme value approximations)

A funny example

A relay race team of several runners only finishes as fast as their slowest-starting runner allows (the whole team is only as good as its worst link) -- each runner's start time is roughly normal, and the team's effective start time follows this power-normal shape.

What's the probability the team's effective start time is below -1?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.powernorm(c=2)
print('P(X < -1):', round(dist.cdf(-1), 4))
print('mean:', round(dist.mean(), 4))
P(X < -1): 0.2921 mean: -0.5642
Theoretical shape at the default parameters above (blue = density/PMF, orange = CDF).
