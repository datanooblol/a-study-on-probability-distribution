Power Lognormal

scipy.stats.powerlognorm

Intuition

This raises the survival function of a lognormal distribution to a power c, which is exactly what happens to the lifetime distribution of a 'series system' made of c identical lognormal-lifetime components -- the whole system fails as soon as its weakest component does.

Formula

\[ f(x;c,s) = \frac{c}{xs}\,\phi\!\left(\frac{\ln x}{s}\right)\left[\Phi\!\left(-\frac{\ln x}{s}\right)\right]^{c-1}, \quad x > 0 \]
parameterdefault used heremeaning
c2power exponent applied to the lognormal CDF
s1shape parameter of the underlying lognormal, sigma

Use cases

  • Series-system reliability modeling (weakest-component failure)
  • Modeling lifetime of systems built from lognormal-lifetime components

A funny example

A string of holiday lights has several bulbs wired so that if any single bulb burns out, the whole string goes dark. Each bulb's lifetime is lognormal, and this distribution describes how long the whole string lasts before the first bulb quits.

What's the probability the light string lasts past 2 (scaled) time units?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.powerlognorm(c=2, s=1)
print('P(lasts > 2):', round(dist.sf(2), 4))
print('median lifetime:', round(dist.median(), 4))
P(lasts > 2): 0.0596 median lifetime: 0.5799
