Wald

scipy.stats.wald

Intuition

Wald is simply the inverse Gaussian distribution with its mean locked at exactly 1 -- a fixed reference version of the same 'first time a drifting random walk crosses a level' story, often used as a standardized building block in sequential-testing theory.

Formula

\[ f(x) = \frac{1}{\sqrt{2\pi x^3}}\exp\!\left(-\frac{(x-1)^2}{2x}\right), \quad x > 0 \]
parameterdefault used heremeaning

Use cases

  • Sequential probability ratio testing in statistics
  • Standardized first-passage-time modeling in drift-diffusion processes

A funny example

Same snail-crawling-to-the-lettuce story as inverse Gaussian, but now the lettuce is always placed at exactly the snail's typical average travel unit away, giving one fixed, standard version of the race to compare against.

What's the probability the snail reaches the lettuce within 0.8 time units?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.wald()
print('P(reaches leaf by t=0.8):', round(dist.cdf(0.8), 4))
print('mean time:', round(dist.mean(), 4))
P(reaches leaf by t=0.8): 0.5747 mean time: 1.0
