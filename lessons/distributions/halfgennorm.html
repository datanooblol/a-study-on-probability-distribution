Half Generalized Normal

scipy.stats.halfgennorm

Intuition

This is the one-sided (positive-only) version of the generalized normal, sliding smoothly between the exponential distribution and the half-normal distribution as the shape parameter beta changes, useful for magnitude data whose 'peakedness' at zero isn't fixed.

Formula

\[ f(x;\beta) = \frac{\beta}{\Gamma(1/\beta)}e^{-x^\beta}, \quad x \ge 0 \]
parameterdefault used heremeaning
beta1.2shape parameter (1 gives exponential, 2 gives half-normal)

Use cases

  • Modeling positive-only signal magnitude with tunable decay shape
  • Image and audio noise magnitude modeling

A funny example

A kid measures how far each of their thrown beanbags lands from a starting line (only distance, never direction), and the shape parameter beta lets you dial in whether short throws are super common or fairly rare.

What's the probability a beanbag lands more than 1.5 units away?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.halfgennorm(beta=1.2)
print('P(X > 1.5):', round(dist.sf(1.5), 4))
print('mean:', round(dist.mean(), 4))
P(X > 1.5): 0.1499 mean: 0.7997
