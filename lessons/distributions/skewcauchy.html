Skew-Cauchy

scipy.stats.skewcauchy

Intuition

This stretches one side of the notoriously wild, mean-less Cauchy distribution more than the other, still keeping the classic Cauchy's extreme unpredictability but adding asymmetry -- useful for robust statistics when outliers are expected but not expected to be symmetric.

Formula

\[ f(x;a) = \frac{1}{\pi\left(\dfrac{x^2}{(a\,\text{sign}(x)+1)^2}+1\right)} \]
parameterdefault used heremeaning
a0.5skewness parameter, -1 < a < 1

Use cases

  • Robust statistics with asymmetric heavy-tailed outlier modeling
  • Financial modeling of skewed, extreme return distributions

A funny example

A weather vane sometimes gets stuck and swings wildly in gusty wind, but a nearby wall makes it more likely to swing extra far to one particular side than the other, so its wild swings are Cauchy-like but lopsided.

What's the probability the vane's reading exceeds 3 on the favored side?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.skewcauchy(a=0.5)
print('P(X > 3):', round(dist.sf(3), 4))
print('median:', round(dist.median(), 4))
P(X > 3): 0.2214 median: 0.866
