Half-Normal

scipy.stats.halfnorm

Intuition

The positive half of a normal distribution centered at zero -- this is exactly the distribution of the absolute value (magnitude) of any zero-mean normal random variable, so it naturally models measurement errors when you only care about size, not sign.

Formula

\[ f(x) = \sqrt{2/\pi}\,e^{-x^2/2}, \quad x \ge 0 \]
parameterdefault used heremeaning

Use cases

  • Modeling magnitude of zero-centered measurement error
  • Bayesian prior for standard deviation parameters

A funny example

A kid's tape measure has a normal-random reading error centered on zero, but the kid only ever records how far off the reading was, never in which direction, so all the errors fold up into positive-only half-normal distances.

What's the probability the measurement error exceeds 1 unit in size?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.halfnorm()
print('P(|error| > 1):', round(dist.sf(1), 4))
print('mean error size:', round(dist.mean(), 4))
P(|error| > 1): 0.3173 mean error size: 0.7979
