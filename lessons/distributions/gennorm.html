Generalized Normal

scipy.stats.gennorm

Intuition

Generalized normal is a dial that morphs a pointy Laplace distribution (beta=1) into the familiar bell curve (beta=2) and onward toward a flat-topped, nearly uniform shape (large beta) -- one formula, a whole spectrum of peakedness.

Formula

\[ f(x;\beta) = \frac{\beta}{2\Gamma(1/\beta)}e^{-|x|^\beta} \]
parameterdefault used heremeaning
beta1.5shape parameter (2 gives normal, 1 gives Laplace, large values approach uniform)

Use cases

  • Modeling image and signal noise with tunable peakedness (image compression)
  • Robust statistics: interpolating between Laplace and normal error models

A funny example

A dartboard's scatter pattern can be pointy-peaked like a tent, rounded like a normal bell, or nearly flat-topped depending on how a single 'peakedness' dial is set on the dart-throwing machine.

With the dial set to beta=1.5, what's the probability a dart lands within 1 unit of the bullseye?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.gennorm(beta=1.5)
print('P(|X| < 1):', round(dist.cdf(1) - dist.cdf(-1), 4))
print('variance:', round(dist.var(), 4))
P(|X| < 1): 0.7752 variance: 0.7385
