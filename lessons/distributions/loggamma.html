Log-Gamma

scipy.stats.loggamma

Intuition

This is the distribution of the logarithm of a gamma-distributed random variable -- it turns gamma's always-positive, right-skewed shape into a distribution defined on the whole real line with a long left tail instead, useful whenever you naturally work in log-space.

Formula

\[ f(x;c) = \frac{\exp(cx-e^x)}{\Gamma(c)}, \quad x \in \mathbb{R} \]
parameterdefault used heremeaning
c3shape parameter (same as the underlying gamma's shape)

Use cases

  • Log-transformed gamma data analysis in biology and reliability
  • Extreme value and order statistics theory

A funny example

A scientist tracks the logarithm of bacteria population counts in a petri dish, since populations grow multiplicatively. Because the raw counts are gamma-shaped, their logarithms follow this log-gamma pattern instead.

What's the probability the log-population value exceeds 1.5?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.loggamma(c=3)
print('P(X > 1.5):', round(dist.sf(1.5), 4))
print('mean:', round(dist.mean(), 4))
P(X > 1.5): 0.1756 mean: 0.9228
