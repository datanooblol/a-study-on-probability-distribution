Alpha

scipy.stats.alpha

Intuition

Alpha comes from taking the reciprocal of a shifted normal variable, which squashes most of the mass close to zero but leaves a very heavy right tail -- so heavy that its mean is technically infinite. It shows up when you model a quantity as '1 over something roughly normal'.

Formula

\[ f(x;a) = \frac{1}{x^2\,\Phi(a)\sqrt{2\pi}} \exp\left(-\frac{1}{2}\left(a-\frac{1}{x}\right)^2\right), \quad x > 0 \]
parameterdefault used heremeaning
a3.5shape parameter controlling how tightly mass clusters near zero

Use cases

  • Modeling reciprocal transformations of normal measurement errors
  • Reliability engineering for extreme-tail failure-time modeling

A funny example

A toy robot's speed is '1 divided by how nervous it is,' and nervousness wobbles like a bell curve. Most days it's only a little nervous, so it zooms off fast, but every once in a great while it's almost perfectly calm and shoots away impossibly fast.

What's the probability the robot's speed value is below 1, and what's its median speed?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.alpha(a=3.5)
print('P(X < 1):', round(dist.cdf(1), 4))
print('median:', round(dist.median(), 4))
P(X < 1): 0.994 median: 0.2857
