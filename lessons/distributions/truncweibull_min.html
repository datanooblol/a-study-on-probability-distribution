Truncated Weibull Minimum

scipy.stats.truncweibull_min

Intuition

A Weibull lifetime distribution restricted to a known observation window -- exactly what happens in a reliability study where you only get to observe failures that occur between the study's start and end dates, never before or after.

Formula

\[ f(x;c,a,b) = \frac{c\,x^{c-1}e^{-x^c}}{e^{-a^c}-e^{-b^c}}, \quad a < x \le b \]
parameterdefault used heremeaning
c1.5Weibull shape parameter
a0.1lower truncation bound
b3upper truncation bound

Use cases

  • Reliability analysis with censored/windowed observation periods
  • Survival analysis of failures observed only within a study window

A funny example

A science teacher runs a classroom experiment tracking how long balloons stay inflated, but the experiment only runs between day 0.1 and day 3 -- any balloon that popped before or is still going after gets cut out of the data, so only failures inside that window count.

What's the probability a recorded balloon pops before day 1.5, given it's within the observed window?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.truncweibull_min(c=1.5, a=0.1, b=3)
print('P(X < 1.5):', round(dist.cdf(1.5), 4))
print('mean:', round(dist.mean(), 4))
P(X < 1.5): 0.8404 mean: 0.9158
