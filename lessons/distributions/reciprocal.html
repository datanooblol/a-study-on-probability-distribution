Reciprocal (Log-Uniform, alias)

scipy.stats.reciprocal

Intuition

Reciprocal is scipy's alias for exactly the same distribution as loguniform: it's uniform on the log scale, which is the natural way to express 'I know the order of magnitude range but nothing more' for a positive quantity spanning several powers of ten.

Formula

\[ f(x;a,b) = \frac{1}{x\ln(b/a)}, \quad a \le x \le b \]
parameterdefault used heremeaning
a1lower bound of the support
b10upper bound of the support

Use cases

  • Same as loguniform: hyperparameter search and scale-parameter priors
  • Historically used in resistor/component value selection ('preferred numbers')

A funny example

A kid guesses how many jellybeans are in a giant jar, somewhere between 1 and 10,000, and treats each power of ten as equally likely rather than each individual count -- that's exactly the reciprocal distribution's logic.

What's the probability the guess falls between 1 and 3?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.reciprocal(a=1, b=10)
print('P(1 < X < 3):', round(dist.cdf(3) - dist.cdf(1), 4))
print('mean:', round(dist.mean(), 4))
P(1 < X < 3): 0.4771 mean: 3.9087
