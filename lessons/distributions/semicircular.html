Wigner Semicircle

scipy.stats.semicircular

Intuition

Famous in random matrix theory: the eigenvalues of a large random symmetric matrix, properly rescaled, pile up into this exact semicircular shape (Wigner's semicircle law) -- a strikingly universal pattern that appears regardless of the details of how the random matrix was built.

Formula

\[ f(x) = \frac{2}{\pi}\sqrt{1-x^2}, \quad -1 \le x \le 1 \]
parameterdefault used heremeaning

Use cases

  • Random matrix theory: eigenvalue distribution (Wigner's semicircle law)
  • Nuclear physics energy-level spacing statistics

A funny example

A kid builds a big grid of dominoes tied together with random-strength springs and measures the natural 'wobble frequencies' of the whole connected system. Plot enough of those frequencies and they trace out a perfect semicircle, no matter the fine details of the springs.

What's the probability a randomly chosen wobble frequency falls between -0.5 and 0.5?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.semicircular()
print('P(-0.5 < X < 0.5):', round(dist.cdf(0.5) - dist.cdf(-0.5), 4))
print('variance:', round(dist.var(), 4))
P(-0.5 < X < 0.5): 0.609 variance: 0.25
