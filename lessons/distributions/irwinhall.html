Irwin-Hall

scipy.stats.irwinhall

Intuition

Irwin-Hall is simply the sum of n independent standard uniform random numbers -- roll n dice-like uniform draws and add them up, and as n grows the lumpy piecewise-polynomial result looks more and more like a normal curve (a hands-on illustration of the Central Limit Theorem).

Formula

\[ f(x;n) = \frac{1}{(n-1)!}\sum_{k=0}^{\lfloor x\rfloor}(-1)^k\binom{n}{k}(x-k)^{n-1}, \quad 0 \le x \le n \]
parameterdefault used heremeaning
n4number of independent uniform(0,1) variables summed

Use cases

  • Central Limit Theorem demonstrations and dice-sum simulations
  • Cardinal B-spline construction in numerical computing and computer graphics

A funny example

A kid picks 4 random decimal numbers between 0 and 1 (like 0.3, 0.71, 0.05, 0.62) and adds them all up. Do that over and over, and the running totals pile up into this specific bell-ish shape, never below 0 or above 4.

What's the probability the sum of the 4 random numbers exceeds 3?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.irwinhall(n=4)
print('P(sum > 3):', round(dist.sf(3), 4))
print('mean sum:', round(dist.mean(), 4))
P(sum > 3): 0.0417 mean sum: 2.0
