Levy-Stable

scipy.stats.levy_stable

Intuition

The stable distributions are the only distributions that a sum of many i.i.d. random variables can converge to (a generalization of the Central Limit Theorem beyond just the normal case) -- alpha controls tail heaviness (2 = normal, smaller = wilder jumps) and beta controls skew, with no closed-form pdf except at special values.

Formula

\[ \varphi(t;\alpha,\beta) = \exp\!\left(it\mu - |ct|^{\alpha}\left(1-i\beta\,\text{sign}(t)\Phi\right)\right) \]
parameterdefault used heremeaning
alpha1.5stability/tail-index parameter, 0 < alpha <= 2 (2 = normal, 1 = Cauchy)
beta0skewness parameter, -1 <= beta <= 1

Use cases

  • Financial market return modeling with heavy tails and skew
  • Generalized Central Limit Theorem for sums of heavy-tailed variables

A funny example

A stock trader watches daily price swings that are wilder and more lopsided than a plain bell curve would predict -- big surprise jumps happen more often than 'normal' would suggest, and this whole family of distributions was built specifically to describe exactly that kind of wild, self-similar randomness.

What's the probability the standardized price swing exceeds 2?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.levy_stable(alpha=1.5, beta=0)
print('P(X > 2):', round(dist.sf(2), 4))
print('median:', round(dist.median(), 4))
P(X > 2): 0.105 median: 0.0
