Truncated Exponential

scipy.stats.truncexpon

Intuition

An exponential distribution that's been given a hard ceiling -- useful whenever a naturally exponential wait time or lifetime is physically capped, such as a lightbulb that's guaranteed to be replaced during scheduled maintenance before it can burn out naturally.

Formula

\[ f(x;b) = \frac{e^{-x}}{1-e^{-b}}, \quad 0 \le x \le b \]
parameterdefault used heremeaning
b4.5upper truncation point (in units of the scale)

Use cases

  • Modeling capped/censored lifetime data in reliability engineering
  • Scheduled-maintenance replacement time modeling

A funny example

A kid's phone battery drains following an exponential-like pattern, but the kid always plugs it in to recharge by bedtime (4.5 hours after unplugging it at the latest), so the battery life is never allowed to run past that cutoff.

What's the probability the battery lasts longer than 3 hours (out of the capped 4.5)?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.truncexpon(b=4.5)
print('P(lasts > 3 hrs):', round(dist.sf(3), 4))
print('mean lifetime:', round(dist.mean(), 4))
P(lasts > 3 hrs): 0.0391 mean lifetime: 0.9494
