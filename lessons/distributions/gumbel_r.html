Gumbel (right-skewed / maximum)

scipy.stats.gumbel_r

Intuition

Gumbel-right describes the distribution of the maximum of many independent random values -- it's the classic model for record-breaking events, with a long tail stretching to the right for the rare occasion the record gets smashed.

Formula

\[ f(x) = e^{-x}\exp\!\left(-e^{-x}\right), \quad x \in \mathbb{R} \]
parameterdefault used heremeaning

Use cases

  • Modeling maximum river flood levels and record-breaking weather
  • Extreme value theory for maxima (annual peak stock returns, wind speeds)

A funny example

A track team records the fastest sprint time set at each week's practice. Most weeks' best times cluster close together, but the shape has a long right tail for the rare week someone has a legendary breakout run.

What's the probability this week's best time (standardized) exceeds 1?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.gumbel_r()
print('P(record > 1):', round(dist.sf(1), 4))
print('mean:', round(dist.mean(), 4))
P(record > 1): 0.3078 mean: 0.5772
