Special Orthogonal Group

scipy.stats.special_ortho_group

Intuition

Just like the Orthogonal Group, but mirror-flips are excluded -- only genuine, physically-realizable rotations (like actually spinning a globe) are allowed.

Formula

\[ \text{Uniform measure over } SO(n) = \{\mathbf{Q}: \mathbf{Q}^T\mathbf{Q}=I,\ \det(\mathbf{Q})=1\} \]
parameterdefault used heremeaning
dim3dimension of the random rotation matrix

Use cases

  • Random 3D rotations in robotics, animation, and molecular simulation
  • Data augmentation via random rotation in 3D machine learning

A funny example

Spinning a globe on its stand to a totally random new orientation -- twisting only, never flipped inside-out like a mirror image.

What does one such random pure-rotation matrix look like?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.special_ortho_group(dim=3)
sample = dist.rvs(random_state=0)
print('one random rotation matrix:')
print(np.round(sample, 3))
one random rotation matrix: [[-0.587 0.485 -0.648] [ 0.745 0.636 -0.198] [ 0.316 -0.6 -0.735]]
