Anglit

scipy.stats.anglit

Intuition

Anglit is a simple bounded, symmetric bump built from a cosine wave -- it's mostly a textbook curiosity used to test distribution-fitting code, but it behaves like a gentle, rounded alternative to the uniform distribution on a narrow interval.

Formula

\[ f(x) = \cos(2x), \quad -\pi/4 \le x \le \pi/4 \]
parameterdefault used heremeaning

Use cases

  • Benchmark distribution for testing statistical software
  • Modeling bounded angular measurement noise

A funny example

A metronome needle swings gently back and forth in a narrow arc, and you snap a photo at a random instant. The needle spends slightly more time hovering near the center of its swing than near the very edges.

What's the probability the needle is caught within 0.2 radians of dead center?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.anglit()
print('P(-0.2 < X < 0.2):', round(dist.cdf(0.2) - dist.cdf(-0.2), 4))
print('mean:', round(dist.mean(), 4))
P(-0.2 < X < 0.2): 0.3894 mean: 0.0
