Dirichlet-Multinomial

scipy.stats.dirichlet_multinomial

Intuition

Multinomial, but the category probabilities themselves are randomly redrawn from a Dirichlet distribution each time -- so counts end up more spread out ('overdispersed') than plain Multinomial would predict.

Formula

\[ P(\mathbf{x}) = \binom{n}{x_1,\ldots,x_k} \frac{B(\alpha+\mathbf{x})}{B(\alpha)} \]
parameterdefault used heremeaning
alpha[2, 3, 5]concentration for each of the k categories
n10number of trials

Use cases

  • Overdispersed text/topic count modeling in NLP
  • Ecological species-count models with extra variability

A funny example

Same pizza-splitting friends as the Dirichlet example, but now imagine repeating the pizza night 10 times, and each friend's typical share wobbles a bit differently every single night.

Across 10 slices total, what's the chance of the exact same 2-3-5 split as the Dirichlet's average tendency?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.dirichlet_multinomial(alpha=[2, 3, 5], n=10)
print('P(split = 2,3,5):', round(float(dist.pmf([2, 3, 5])), 4))
P(split = 2,3,5): 0.0409
