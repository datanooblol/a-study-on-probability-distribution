Kolmogorov-Smirnov Two-Sided

scipy.stats.kstwo

Intuition

The two-sided cousin of ksone, this is the exact finite-sample distribution of the largest gap in either direction between an empirical CDF built from n points and the true distribution -- it's what scipy's kstest function actually uses to compute p-values.

Formula

\[ F_n(d) = P(D_n \le d), \quad D_n = \sup_x |F_{\text{emp}}(x) - F(x)| \]
parameterdefault used heremeaning
n20sample size used in the two-sided KS test statistic

Use cases

  • Kolmogorov-Smirnov two-sided goodness-of-fit testing
  • Computing exact p-values for the scipy.stats.kstest function

A funny example

Same die-rolling kid as before, but now checking the biggest gap between their tally chart and the fair-die ideal in either direction (too high or too low), not just one specific direction.

With 20 rolls, what's the probability that biggest two-sided gap exceeds 0.3?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.kstwo(n=20)
print('P(D > 0.3):', round(dist.sf(0.3), 4))
print('mean D:', round(dist.mean(), 4))
P(D > 0.3): 0.0431 mean D: 0.1863
