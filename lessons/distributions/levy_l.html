Levy (left-skewed)

scipy.stats.levy_l

Intuition

The mirror image of the Levy distribution reflected onto the negative numbers -- same extremely heavy, infinite-mean tail, just facing the other direction, useful whenever the 'wild jump' phenomenon naturally points toward negative values (like sudden negative shocks).

Formula

\[ f(x) = \sqrt{\frac{1}{2\pi |x|^3}}\exp\!\left(-\frac{1}{2|x|}\right), \quad x \le 0 \]
parameterdefault used heremeaning

Use cases

  • Modeling sudden negative shocks or jumps in a process
  • Stable-distribution theory (alpha=0.5 stable family member)

A funny example

Instead of a seagull hopping toward food, imagine a marble rolling down a hill that occasionally takes one enormous unpredictable tumble further downhill, in an unbounded 'always toward negative' direction.

What's the probability the marble's tumble distance is more negative than -3?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.levy_l()
print('P(X < -3):', round(dist.cdf(-3), 4))
print('median:', round(dist.median(), 4))
P(X < -3): 0.4363 median: -2.1981
