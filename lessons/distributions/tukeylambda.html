Tukey Lambda

scipy.stats.tukeylambda

Intuition

Tukey lambda is defined by its quantile (inverse-CDF) function rather than a closed-form pdf, and a single knob lambda smoothly sweeps through shapes from heavy-tailed logistic, through something extremely close to normal (near lambda=0.14), all the way to the flat uniform distribution (lambda=1).

Formula

\[ Q(p;\lambda) = \frac{p^\lambda-(1-p)^\lambda}{\lambda} \]
parameterdefault used heremeaning
lam0.14shape parameter (0 gives logistic, 0.14 approximates normal, 1 gives uniform)

Use cases

  • Flexible family for exploratory data analysis and QQ-plot shape diagnostics
  • Simulating data with tunable tail weight for robustness studies

A funny example

A toy 'shape machine' has one dial: turn it one way and the output looks like a fat-tailed logistic curve, turn it to the sweet spot and it looks almost exactly like a normal bell curve, turn it further and it flattens all the way out to a uniform block.

At the near-normal setting (lambda=0.14), what's the probability the output falls between -1 and 1?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.tukeylambda(lam=0.14)
print('P(-1 < X < 1):', round(dist.cdf(1) - dist.cdf(-1), 4))
print('variance:', round(dist.var(), 4))
P(-1 < X < 1): 0.5095 variance: 2.1103
