Power Function

scipy.stats.powerlaw

Intuition

The simplest possible bounded power-law shape: a raw x^(a-1) density on [0,1] that's the a-th order statistic pattern of uniform samples -- when a>1 mass piles up near 1, when a<1 it piles up near 0, and a=1 reduces exactly to the uniform distribution.

Formula

\[ f(x;a) = a\,x^{a-1}, \quad 0 \le x \le 1 \]
parameterdefault used heremeaning
a2.5shape (power) parameter

Use cases

  • Order statistics: distribution of the maximum of uniform samples
  • Modeling skewed bounded proportions in reliability testing

A funny example

A kid runs a raffle where the ticket that gets picked already has a bias baked in: because of how the power-law dial is set, tickets with higher numbers (closer to the top of the range) are more likely to win than lower ones.

What's the probability the winning ticket value is below 0.5?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.powerlaw(a=2.5)
print('P(X < 0.5):', round(dist.cdf(0.5), 4))
print('mean:', round(dist.mean(), 4))
P(X < 0.5): 0.1768 mean: 0.7143
