Kolmogorov-Smirnov One-Sided

scipy.stats.ksone

Intuition

This is the exact sampling distribution of the one-sided Kolmogorov-Smirnov statistic -- the biggest amount by which an empirical cumulative distribution built from n data points can stray above the true distribution -- and it's the basis of the classic KS goodness-of-fit test.

Formula

\[ P(D_n^+ < d) = 1 - d\sum_{j=0}^{\lfloor n(1-d)\rfloor}\binom{n}{j}\left(\frac{j}{n}+d\right)^{j-1}\left(1-d-\frac{j}{n}\right)^{n-j} \]
parameterdefault used heremeaning
n20sample size used in the one-sided KS test statistic

Use cases

  • Kolmogorov-Smirnov goodness-of-fit hypothesis testing
  • Assessing how well an empirical sample matches a theoretical distribution

A funny example

A kid rolls a die 20 times and draws a running tally chart, comparing it to what a perfectly fair die 'should' look like. This distribution measures the single biggest gap between the kid's chart and the fair-die ideal, in one direction.

With 20 rolls, what's the probability that biggest one-sided gap exceeds 0.3?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.ksone(n=20)
print('P(D+ > 0.3):', round(dist.sf(0.3), 4))
print('mean D+:', round(dist.mean(), 4))
P(D+ > 0.3): 0.0215 mean D+: 0.1323
