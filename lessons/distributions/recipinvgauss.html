Reciprocal Inverse Gaussian

scipy.stats.recipinvgauss

Intuition

This is exactly what you get by taking 1/X when X follows an inverse Gaussian distribution -- since inverse Gaussian itself models first-passage times, its reciprocal naturally models rates (like speed = 1/time) derived from those same drift-diffusion processes.

Formula

\[ f(x;\mu) = \frac{1}{\sqrt{2\pi x}}\exp\!\left(-\frac{(1-\mu x)^2}{2\mu^2 x}\right), \quad x \ge 0 \]
parameterdefault used heremeaning
mu1shape parameter (mean of the underlying inverse Gaussian's reciprocal)

Use cases

  • Rate/speed modeling as the reciprocal of first-passage time processes
  • Diffusion-model parameter transformations in cognitive science

A funny example

Instead of timing how long the snail takes to reach the lettuce (inverse Gaussian), a kid instead calculates the snail's average speed for the trip -- 1 divided by the time -- which follows this reciprocal inverse Gaussian shape.

What's the probability the snail's average speed exceeds 1.5?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.recipinvgauss(mu=1)
print('P(speed > 1.5):', round(dist.sf(1.5), 4))
print('mean speed:', round(dist.mean(), 4))
P(speed > 1.5): 0.4939 mean speed: 2.0
