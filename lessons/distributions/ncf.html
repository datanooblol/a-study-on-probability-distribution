Noncentral F

scipy.stats.ncf

Intuition

This is the distribution of the F-statistic in ANOVA when the null hypothesis (no real group difference) is actually false -- the noncentrality parameter measures the true effect size, and statisticians use it to compute the statistical power of an F-test before running the experiment.

Formula

\[ f(x;d_1,d_2,\lambda) = \sum_{k=0}^\infty \frac{e^{-\lambda/2}(\lambda/2)^k}{k!}\,\frac{(d_1/d_2)^{d_1/2+k}\,x^{d_1/2+k-1}}{B\!\left(\frac{d_1}{2}+k,\frac{d_2}{2}\right)\left(1+\frac{d_1}{d_2}x\right)^{(d_1+d_2)/2+k}} \]
parameterdefault used heremeaning
dfn10numerator degrees of freedom
dfd20denominator degrees of freedom
nc3noncentrality parameter (effect size)

Use cases

  • Statistical power analysis for ANOVA and F-tests
  • Effect-size detection in experimental design

A funny example

A science-fair judge compares average scores across several different classroom projects using an F-test. If there really is a genuine difference between the classrooms (not just random noise), the F-statistic follows this noncentral shape instead of the plain central F distribution.

What's the probability the F-statistic exceeds 2, given there's a real effect present?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.ncf(dfn=10, dfd=20, nc=3)
print('P(F > 2):', round(dist.sf(2), 4))
print('mean F:', round(dist.mean(), 4))
P(F > 2): 0.196 mean F: 1.4444
