Johnson SB (bounded)

scipy.stats.johnsonsb

Intuition

Johnson SB transforms a normal random variable through a logit-style function to squeeze it onto a bounded (0,1) interval -- it's part of the Johnson system, a set of transformations built to fit almost any real dataset's shape by matching its mean, variance, skewness and kurtosis.

Formula

\[ f(x;a,b) = \frac{b}{x(1-x)\sqrt{2\pi}}\exp\!\left(-\frac{1}{2}\left(a+b\ln\frac{x}{1-x}\right)^2\right), \quad 0 < x < 1 \]
parameterdefault used heremeaning
a1shape parameter controlling skewness
b2shape parameter controlling how tightly mass concentrates

Use cases

  • Fitting bounded empirical data (percentages, proportions) to a flexible parametric shape
  • Financial modeling of bounded asset prices or ratios

A funny example

A teacher grades homework as a percentage from 0% to 100%. Rather than a plain uniform spread, the scores cluster and skew in a specific way that this bounded, transformed-normal shape captures well.

What's the probability a score falls below 0.4 (40%)?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.johnsonsb(a=1, b=2)
print('P(X < 0.4):', round(dist.cdf(0.4), 4))
print('mean:', round(dist.mean(), 4))
P(X < 0.4): 0.575 mean: 0.384
