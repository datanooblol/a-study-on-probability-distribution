Burr Type XII

scipy.stats.burr12

Intuition

Burr Type XII is the 'mirror' of the Burr distribution above (it's the reciprocal-transform relative) and is the classic choice for reliability engineers modeling how long products survive before failing, since it can mimic a bathtub-shaped or steadily increasing hazard.

Formula

\[ f(x;c,d) = c\,d\,x^{c-1}(1+x^c)^{-d-1}, \quad x > 0 \]
parameterdefault used heremeaning
c3shape parameter controlling the rise near the origin
d6shape parameter controlling the tail's decay rate

Use cases

  • Reliability and survival analysis (time-to-failure modeling)
  • Flood and hydrology data fitting

A funny example

A toy company stress-tests a new wind-up robot by counting how many days it runs before its spring breaks. Some break almost immediately, most last a solid while, and a few keep ticking long past when everyone expected them to quit.

What's the probability the robot lasts more than 1 day, and what's the expected number of days it runs?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.burr12(c=3, d=6)
print('P(lasts > 1 day):', round(dist.sf(1), 4))
print('expected days:', round(dist.mean(), 4))
P(lasts > 1 day): 0.0156 expected days: 0.5109
