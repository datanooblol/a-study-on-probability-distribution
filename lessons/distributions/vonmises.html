Von Mises

scipy.stats.vonmises

Intuition

The 'circular normal' distribution: it plays the same role for angles and directions that the normal distribution plays for straight-line measurements, correctly wrapping around so that an angle near +pi is treated as close to an angle near -pi.

Formula

\[ f(x;\kappa) = \frac{e^{\kappa\cos x}}{2\pi I_0(\kappa)}, \quad -\pi \le x \le \pi \]
parameterdefault used heremeaning
kappa3concentration parameter (higher = tighter clustering around the mean direction)

Use cases

  • Directional/circular statistics for wind direction and compass bearings
  • Modeling phase angles in signal processing and biological rhythms

A funny example

A kid uses a compass to note which direction a weathervane points every hour on a windy day. It mostly points in one favorite direction but wobbles around it, and because compass directions wrap around (0 and 360 degrees are the same), you need a distribution built specifically for circles.

What's the probability the weathervane points within 1 radian of its favorite direction?

Solve it with scipy.stats

import scipy.stats as stats
import numpy as np

dist = stats.vonmises(kappa=3)
print('P(-1 < angle < 1):', round(dist.cdf(1) - dist.cdf(-1), 4))
print('circular mean:', round(dist.mean(), 4))
P(-1 < angle < 1): 0.8809 circular mean: -0.0
